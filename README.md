# Quartz — Personal Portfolio

A buildless, responsive portfolio for GitHub Pages.

## Preview

Run `python3 -m http.server 4173` in this folder.

## Deploy

GitHub Settings → Pages → Deploy from a branch → main / (root).

## Content

Four featured products and eight additional public software projects. All screenshots and photography are from Quartzsyr’s public repositories. Edit index.html for content, style.css for design, and site.js for interactions. No runtime dependencies, analytics, or build step.

Design references: https://brittanychiang.com/ (information hierarchy), https://bruno-simon.com/ (playful interaction). Original design and implementation.
